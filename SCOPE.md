# Scope

1. Log in to the site with a username and password from a config file.
2. See a real, live Chromium in the page, with an address bar and back/forward.
3. Click, type, and scroll in it with correct coordinate scaling.
4. Sign into Google by hand inside it, with the session saved between visits.
